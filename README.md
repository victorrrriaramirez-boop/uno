# NÓRDEN — demo de portfolio

Sitio ficticio e independiente: arquitectura minimalista y recorrido horizontal de proyectos. Su contenido sirve para mostrar un concepto visual; la empresa, los proyectos y el correo `hola@ejemplo.com` no corresponden a una actividad real.

## Publicación en GitHub y Vercel

1. Descomprime este ZIP y crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `style.css` y `motion.js` a la raíz del repositorio. Puedes hacerlo con **Add file → Upload files → Commit changes**.
3. En [Vercel](https://vercel.com/new), selecciona **Import Git Repository** e importa el repositorio.
4. Deja `./` como directorio raíz y pulsa **Deploy**. Es una web estática; no requiere framework, instalación ni compilación.

## Personalización

Cambia nombres, textos, fotografías y el enlace `mailto:hola@ejemplo.com` antes de reutilizar esta demo para una empresa real. Las imágenes de ejemplo se sirven desde Unsplash y las fuentes desde Google Fonts; para una entrega de cliente conviene usar materiales propios y comprobar sus licencias y disponibilidad. La navegación móvil incluye un menú desplegable; el scrolltelling se adapta al tamaño de pantalla y las animaciones respetan `prefers-reduced-motion`. Los asteriscos, estrellas y flechas decorativas se han eliminado.

## Vista local

En esta carpeta, ejecuta `python3 -m http.server 8000` y abre `http://localhost:8000`.
