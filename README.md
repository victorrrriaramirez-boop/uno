# NÓRDEN — El espacio entre las cosas

Archivo arquitectónico editorial con portada dividida, escaneo de luz e índice de proyectos que acompaña el scroll.

## Publicar en GitHub y Vercel
1. Descomprime el ZIP.
2. Sube index.html, style.css, motion.js, README.md y la carpeta assets a la raíz de un repositorio de GitHub.
3. Importa el repositorio en Vercel, selecciona Other, sin comando de instalación ni build y con directorio raíz como salida.

## Vista local
Ejecuta `python3 -m http.server 8000` y abre http://localhost:8000.

## Contenido y accesibilidad
Marca ficticia para portfolio. Los controles y recorridos funcionan localmente. No hay pagos, reservas ni envíos reales. Fotografías externas de Unsplash; el sitio requiere conexión para cargarlas. Movimiento reducido mediante prefers-reduced-motion. Sin flechas ni asteriscos decorativos. HTML semántico, controles de teclado y diseños móviles específicos.

## Comparador de reforma
La portada revela el antes y el después con una línea horizontal que recorre la imagen verticalmente. Dispone de reproducción/pausa y control manual mediante rango, compatible con teclado y pantalla táctil. Al manipular el control se detiene la reproducción. Se pausa fuera de pantalla o al ocultar la pestaña. Con movimiento reducido comienza detenido. La imagen local en assets/reforma-conceptual.png contiene las dos vistas y debe subirse junto a los demás archivos. Es una reforma conceptual generada con IA, no un caso real.
